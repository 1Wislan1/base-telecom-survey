# Опрос клиентов «Бейс Телеком»

Короткий опрос из 13 шагов. Работает как обычный сайт на GitHub Pages, а ответы сами приходят в вашу Google Таблицу. Платные сервисы и свой сервер не нужны.

```
GitHub Pages  →  HTML / CSS / JS  →  Google Apps Script  →  Google Таблица
```

## Что внутри

| Файл | Для чего |
|---|---|
| `index.html` | Страница: приветствие, вопросы, проверка, «спасибо» |
| `style.css` | Внешний вид: цвета, шрифты, кнопки, мобильная версия |
| `script.js` | Логика: вопросы, прогресс, проверка, отправка |
| `google-apps-script/Code.gs` | Код, который принимает ответы и пишет их в таблицу |
| `assets/` | Сюда кладётся логотип (`logo.svg`), подробности в `assets/README.md` |

Сайт сразу открывается и работает. Пока вы не вставили адрес Google Apps Script, он в **демо-режиме**: опрос проходится полностью, но ответы никуда не отправляются (их видно только в консоли браузера).

## ШАГ 1. Создайте репозиторий на GitHub

1. Зайдите на https://github.com и войдите (или нажмите **Sign up** и зарегистрируйтесь, это бесплатно).
2. Вверху справа нажмите **+** → **New repository**.
3. В поле **Repository name** напишите, например: `base-survey` (латиницей, без пробелов).
4. Выберите **Public** (для бесплатного GitHub Pages это нужно).
5. Галочки **Add a README** не ставьте.
6. Нажмите зелёную кнопку **Create repository**.

## ШАГ 2. Какие файлы загружать

Загрузить нужно всё из этого проекта:

- `index.html`
- `style.css`
- `script.js`
- `README.md`
- папку `google-apps-script` (внутри `Code.gs`)
- папку `assets` (внутри `README.md`)

Загружать лучше после шагов 3–8, чтобы сразу выложить версию с вашим адресом. Но можно и сейчас, а потом заменить `script.js`.

## ШАГ 3. Создайте Google Таблицу

1. Откройте https://sheets.google.com и нажмите **Пустая таблица** (знак «+»).
2. Вверху слева дайте таблице название, например: `Опрос Бейс Телеком`.
3. Внизу найдите вкладку **Лист1**, нажмите на неё правой кнопкой → **Переименовать** → напишите `Ответы` → Enter.

Заголовки писать вручную не надо, скрипт создаст их сам.

## ШАГ 4. Откройте Apps Script

1. В вашей таблице в верхнем меню нажмите **Расширения** → **Apps Script**.
2. Откроется новая вкладка с редактором кода. Важно открывать его именно из таблицы, тогда скрипт «привязан» к ней.

## ШАГ 5. Вставьте код Code.gs

1. В редакторе слева нажмите на файл `Код.gs` (или `Code.gs`).
2. Выделите весь текст в окне (Ctrl+A на компьютере) и удалите его.
3. Откройте файл `google-apps-script/Code.gs` из этого проекта, скопируйте **весь** текст и вставьте в окно редактора.
4. Нажмите значок дискеты **Сохранить проект** (или Ctrl+S).
5. Вверху выберите в списке функцию `authorizeScript` и нажмите **Выполнить**.
6. Google попросит разрешение:
   - нажмите **Просмотреть разрешения**;
   - выберите свой аккаунт;
   - если увидите «Google не проверил это приложение», нажмите **Дополнительно** → **Перейти на страницу «Проект без названия» (небезопасно)**. Это ваш собственный скрипт, ему можно доверять;
   - нажмите **Разрешить**.
7. Вернитесь в таблицу: в листе **Ответы** появилась первая строка с заголовками.

## ШАГ 6. Разверните как Web App

1. В Apps Script справа вверху нажмите синюю кнопку **Начать развёртывание** → **Новое развёртывание**.
2. Нажмите на шестерёнку рядом с надписью «Выберите тип» → **Веб-приложение**.
3. Заполните:
   - **Описание:** `Опрос v1`
   - **Execute as / Запуск от имени:** **Me / Я** (ваш аккаунт)
   - **Who has access / У кого есть доступ:** **Anyone / Все**
4. Нажмите **Начать развёртывание**.

## ШАГ 7. Скопируйте URL Web App

1. После развёртывания появится окно с **URL веб-приложения**. Он выглядит так: `https://script.google.com/macros/s/ДЛИННЫЙ_НАБОР_БУКВ/exec`.
2. Нажмите **Копировать** и сохраните адрес (например, отправьте себе в заметки).
3. Проверка: вставьте этот адрес в новую вкладку браузера. Должен появиться текст со словами `"ok":true`. Значит всё работает.

## ШАГ 8. Вставьте URL в script.js

1. Откройте файл `script.js` (в блокноте или прямо на GitHub после загрузки: нажмите на файл → значок карандаша).
2. В самом начале найдите строку:

   ```js
   const GOOGLE_SCRIPT_URL = "";
   ```

3. Вставьте адрес между кавычками:

   ```js
   const GOOGLE_SCRIPT_URL = "https://script.google.com/macros/s/ВАШ_АДРЕС/exec";
   ```

4. Сохраните файл. Больше нигде адрес менять не нужно.

## ШАГ 9. Загрузите проект на GitHub

1. Откройте ваш репозиторий (шаг 1).
2. Нажмите **uploading an existing file** (или **Add file** → **Upload files**).
3. Перетащите в окно все файлы и папки из проекта (`index.html`, `style.css`, `script.js`, `README.md`, папки `google-apps-script` и `assets`).
4. Дождитесь, пока все файлы появятся в списке.
5. Внизу нажмите зелёную кнопку **Commit changes**.

## ШАГ 10. Включите GitHub Pages

1. В репозитории нажмите **Settings** (вверху справа в строке вкладок).
2. Слева выберите **Pages**.
3. В разделе **Build and deployment** → **Source** выберите **Deploy from a branch**.
4. Ниже в **Branch** выберите **main**, а рядом папку **/ (root)**.
5. Нажмите **Save**.
6. Подождите 1–2 минуты и обновите страницу. Сверху появится адрес сайта: `https://ВАШ_ЛОГИН.github.io/base-survey/`. Это и есть ссылка на опрос, её можно отправлять клиентам.

## ШАГ 11. Проверьте отправку

1. Откройте сайт по ссылке с телефона или компьютера.
2. Нажмите **Пройти опрос** и ответьте на все вопросы.
3. **Важно:** быстрее чем за 10 секунд опрос пройти нельзя. Это защита от ботов: если проскочить слишком быстро, сайт покажет «Спасибо», но ничего не запишет. Когда тестируете, не спешите.
4. На экране проверки нажмите **Отправить ответы**.
5. Должно появиться «Спасибо за ваш отзыв!».

## ШАГ 12. Посмотрите результаты

1. Откройте вашу Google Таблицу, лист **Ответы**.
2. Каждый новый ответ добавляется новой строкой: дата, время, оценки, комментарии и т. д.
3. Таблицу можно скачать: **Файл** → **Скачать** → **Microsoft Excel**.

## Как изменить что-то позже

| Что поменять | Где |
|---|---|
| **Логотип** | Положить файл `assets/logo.svg` (см. `assets/README.md`) |
| **Цвета** | `style.css`, самый верх, блок `:root` (`--primary` синий, `--accent` красный и т. д.) |
| **Вопросы и варианты ответов** | `script.js`, блок `QUESTIONS` (раздел «3. ВОПРОСЫ»). Править текст в `title` и `options` |
| **Обязательный или нет вопрос** | `script.js`, у вопроса `required: true` или `false` |
| **Тексты главного экрана** | `index.html`, раздел «ЭКРАН 1. ПРИВЕТСТВИЕ» |
| **Текст «Спасибо»** | `index.html`, раздел «ЭКРАН 4. СПАСИБО» |
| **URL Google Apps Script** | `script.js`, строка `const GOOGLE_SCRIPT_URL = "..."` (самое начало) |
| **Минимальное время прохождения** | `script.js`, `MIN_FILL_SECONDS` |

### Важно, если меняете вопросы

Заголовки таблицы и сами поля жёстко заданы в `google-apps-script/Code.gs`. Менять **формулировки** вопросов и **варианты** ответов можно свободно. Но добавление нового вопроса потребует правки и `script.js`, и `Code.gs` (и нового развёртывания). Для этого лучше позвать меня.

### Если изменили Code.gs

Изменения не применятся сами. В Apps Script нажмите **Начать развёртывание** → **Управление развёртываниями** → значок карандаша → в поле **Версия** выберите **Новая версия** → **Развернуть**. Адрес при этом останется тот же.

## Если что-то не работает

- **«Спасибо» появилось, а в таблице пусто.** Либо вы прошли опрос быстрее 10 секунд, либо в `script.js` не вставлен адрес (тогда на экране «Спасибо» виден жёлтый текст про демо-режим).
- **Пишет «Не удалось отправить ответы».** Проверьте, что в Apps Script выбрано **Who has access: Anyone** (шаг 6) и что адрес в `script.js` заканчивается на `/exec`. Нажмите «Повторить отправку»: ответы не потеряются и дубликатов не будет.
- **Сайт не обновился после загрузки.** Подождите 1–2 минуты и обновите страницу с очисткой кэша (Ctrl+F5, на телефоне откройте в режиме инкогнито).
- **Не видно логотипа.** Файл должен называться `logo.svg` и лежать в папке `assets`.
- **Страница GitHub Pages даёт ошибку 404.** Проверьте шаг 10: ветка **main**, папка **/ (root)**, а файл `index.html` лежит в корне репозитория (не внутри лишней папки).

## Что собирает опрос

Только то, что вы видите в вопросах. ФИО не спрашивается. Телефон необязателен и сохраняется только если человек ответил «Да» на вопрос о связи.
