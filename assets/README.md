# Папка assets — как поставить настоящий логотип

Сейчас вместо логотипа на сайте показан аккуратный текст:

```
БЕЙС
ТЕЛЕКОМ
```

Настоящий логотип я не выдумывал. Когда он у вас будет, замена занимает минуту.

## Как заменить

1. Подготовьте файл логотипа в формате **SVG** (лучше всего) и назовите его ровно так: `logo.svg` (маленькими буквами).
2. Положите его в эту папку: `assets/logo.svg`.
3. Загрузите файл в GitHub (кнопка **Add file → Upload files**, папка `assets`).
4. Подождите 1–2 минуты и обновите сайт (на телефоне можно открыть в режиме инкогнито — так не мешает старая версия из кэша).

Больше ничего менять не нужно: сайт сам проверит, есть ли файл, и подставит его вместо текста.

## Советы по файлу

- Логотип должен хорошо смотреться на **светлом фоне** (шапка сайта светло-серая).
- Размер логотипа на сайте ограничен: высота 40 px, ширина не больше 200 px. Лишнего растягивания не будет.
- Если у вас только PNG — тоже можно, но тогда в файле `script.js` в двух местах замените `logo.svg` на `logo.png` (ищите слово `loadLogo`).

## Как убрать логотип и вернуть текст

Просто удалите файл `assets/logo.svg` из репозитория.
